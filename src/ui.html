Altium → Boardview

Выгрузки из Altium превращаются в .brd и .bvr для OpenBoardView и FlexBV, плюс .json с номиналами для Boardview Reader. Всё считается в браузере, файлы никуда не отправляются.

    Как выгрузить из Altium
    1. Сам .PcbDoc, лучший вариант: просто перетащите файл платы из проекта. Из него берутся пады, цепи, контур и номиналы (если на плате есть текст Comment).
    2. PCB ASCII, если .PcbDoc почему-то не читается. В PCB: File → Save As (или Save Copy As) → тип PCB ASCII File (*.PcbDoc). Внутри все пады с координатами, цепи и контур платы.
    3. IPC-D-356A, если ASCII не подходит. File → Fabrication Outputs → Test Point Report → формат IPC-D-356A. Если деталей или пинов мало, значит, в отчёт попали только тестовые точки.
    4. Контур, по желанию: Gerber слоя Board Outline (.GKO, .GM1 и т.п.), если плата не прямоугольная.
    верхниз
    Нажмите на пин, чтобы подсветить цепь. Колесо — масштаб, перетаскивание — сдвиг. Вид снизу зеркальный, как у ноутбучных boardview.
